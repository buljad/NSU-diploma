# Stabilometer

Локальное приложение для работы с четырёхдатчиковой стабилоплатформой: запись центра давления, тренировка «Поймай мяч», карточки участников, архив и отчёты.

## Запуск готовой Windows-версии

1. Распакуйте всю папку `Stabilometer-1.1.0-windows-x64` в доступный каталог.
2. Запустите `START.cmd`. Включённый Node.js находится в `runtime`; устанавливать pnpm и среду разработки не требуется.
3. Откроется `http://127.0.0.1:5173`. Оставьте окно запуска работающим. Для завершения нажмите Ctrl+C в этом окне.
4. Используйте современный Chrome или Edge. Для архива необходимы IndexedDB и Web Locks. Одновременно архив открывается одной вкладкой.

Веб-интерфейс и WebSocket работают только на этом компьютере (порты 5173 и 3001). Интернет для штатной работы не нужен. При повторном запуске сначала закройте прежнее окно приложения. Для реальной платформы нужен подходящий USB/COM-драйвер производителя.

## Первая сессия

1. В разделе **Устройство** подключите COM-порт. Для знакомства можно включить демонстрацию без оборудования.
2. Освободите платформу и выполните калибровку. Это определение нуля датчиков, а не положения стоящего человека. Настройте ориентацию осей.
3. В разделе **Участники** создайте карточку. Можно использовать код вместо имени.
4. Выберите условия измерения, положение стоп и длительность. Условия выбирает специалист; предустановки интерфейса не заменяют методику.
5. Нажмите **Начать измерение**. После обратного отсчёта записывается каждый полученный пакет. По окончании выбранного времени запись сохраняется автоматически. Ручная досрочная остановка сохраняет запись с отметкой о прерывании.
6. Откройте **Историю**: траекторию, показатели, замечания качества, комментарий и сравнение с другой записью.
7. **Отчёт / PDF** открывает печатный документ; внутри нажмите **Печать / сохранить PDF** и выберите сохранение PDF в браузере. CSV и JSON доступны отдельно.

Для тренировки выберите участника и сложность в разделе **Тренировка**. Управляйте корзиной центром давления, ловите целевые мячи. Ручная пауза сохраняется до команды продолжения. При потере свежего сигнала игра приостанавливается; после восстановления данные снова используются. Досрочная остановка сохраняет доступные очки. Демонстрационные записи всегда отмечаются отдельно.

## Хранение, перенос и удаление

- Полные измерения сохраняются в IndexedDB браузера блоками, контрольная точка — каждые 2 секунды. При аварийном завершении возможна потеря последнего интервала. Сохранённая часть восстанавливается как прерванная запись при следующем запуске.
- Архив привязан к профилю браузера и адресу **http://127.0.0.1:5173**. `localhost`, другой порт или другой профиль — другое хранилище. Очистка данных браузера удаляет локальную базу.
- В **Истории** регулярно скачивайте **Резервную копию** и храните её вне каталога приложения. Для переноса импортируйте её на другом компьютере. Импорт добавляет записи, совпадающие идентификаторы заменяет; весь архив проверяется до записи, изменения применяются одной транзакцией.
- JSON отдельной сессии служит для анализа; для восстановления всей картотеки используйте резервную копию.
- Комментарии, карточки и выгруженные файлы могут содержать персональные сведения. Доступ к профилю компьютера и резервным копиям организует владелец установки.
- Калибровка хранится отдельно в пользовательском каталоге `Stabilometer`. Переменная `STABILOMETER_DATA_DIR` позволяет выбрать другой каталог. Старый `calibration.json` читается как резервный источник. Калибровка и ориентация осей фиксируются в записи.

## Обработка данных

Аналитика использует `centered`: откалиброванные координаты после преобразования осей **до серверного и визуального сглаживания**. Интерполяция и фильтр Калмана служат только отображению и игре. Частота экрана не влияет на метрики.

Время берётся из возрастающих миллисекунд устройства; при недоступности используется время сервера, затем монотонное время получения. Смена источника/сброс часов отмечаются. Разрывы больше 250 мс и невалидные отсчёты не соединяются при расчёте пути и скорости. Подробный метод, версия алгоритма, наблюдаемое время и ковариационный эллипс 95% приведены в отчёте. Зона и игровые очки не являются нормативной клинической оценкой.

Четыре датчика общей платформы не дают карты давления под стопами или независимого измерения каждой ноги. Протокол оборудования не содержит контрольной суммы, поэтому не всякая порча байтов обнаружима программно. Сообщения парсера — ошибки разбора, а не точный счётчик потерянных физических пакетов. Единицы силы остаются условными: показания не следует выдавать за килограммы.

## Разработка

Требуются Node.js >=20.19 и pnpm >=8. Существующие зависимости устанавливаются `pnpm install --frozen-lockfile`.

```sh
pnpm dev                 # локальный сервер и Vite
pnpm check               # TypeScript + Svelte
pnpm test                # численные, протокольные и WebSocket-тесты
pnpm build               # серверный bundle + статический клиент
pnpm start               # запуск production-сборки
pnpm package:windows     # переносная папка с Node.js и runtime-зависимостями
```

Сборка Windows-пакета выполняется на Windows с установленными зависимостями. Результат — `release/Stabilometer-<version>-windows-<arch>`. Существующую папку дистрибутива скрипт не перезаписывает. Сборку другой архитектуры следует проверять отдельно. Пакет переносной; подписанный установщик и автоматические обновления пока не реализованы.

`packages/shared` содержит протокол и математику, `packages/server` — оборудование и WebSocket, `packages/client/src/lib/sessions` — запись, расчёты, IndexedDB, экспорт; Canvas отвечает за отображение. Скрипты сборки используют установленный esbuild из зависимостей Vite, не требуют дополнительных сетевых загрузок.

## Перед передачей пользователям

Проверьте платформу известной нагрузкой в известных точках, повторяемость, дрейф, отключение кабеля, работу после перезапуска и восстановление резервной копии. Аппаратная точность и клиническая применимость программными тестами не подтверждаются. Требуемые характеристики и допустимое назначение устанавливаются по результатам аппаратных испытаний.
